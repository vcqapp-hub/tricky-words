TRICKY WORDS WEBSITE
====================

Included:
- index.html — complete responsive landing page
- assets/ — optimized supplied promotional images
- favicon.svg — simple Tricky Words favicon
- robots.txt — crawler access
- sitemap.xml — search engine sitemap
- llms.txt — machine-readable summary for AI systems

BEFORE PUBLISHING
1. Replace https://YOUR-DOMAIN.example/ with the final website URL.
2. Replace YOUR_PACKAGE_NAME with the Android package ID.
3. Replace YOUR DEVELOPER NAME in the JSON-LD publisher field.
4. Replace the Google Play links with the final Play Store URL.

IMPORTANT ABOUT GOOGLE SITES
Google Sites does not give you normal control over robots.txt, sitemap.xml or server-side SEO.
For maximum search-engine and AI discoverability, publish this folder as a normal website (GitHub Pages, Cloudflare Pages, Netlify, etc.).
If you still want Google Sites, you can embed the hosted page by URL, but the standalone host should remain the canonical/SEO site.

GOOGLE SITES EMBED
After hosting the site, use Google Sites -> Insert -> Embed -> By URL and paste the final site URL.
